# Identité visuelle de JDR Hub

## Logo officiel

Le logo officiel est :

- `docs/branding/logo.svg`


Il est interdit de redessiner, recolorer ou remplacer ce logo.

## Header de référence

Le header de référence est celui de la maquette :

- `docs/maquettes/desktop/landing-page/`

La version mobile de référence est :

- `docs/maquettes/mobile/landing-page/`

Toutes les pages doivent reprendre le même header.

## Priorité visuelle

En cas de différence entre les maquettes :

1. logo présent dans `docs/branding/` ;
2. landing page desktop ;
3. landing page mobile ;
4. cohérence générale du design system.
