# F00 Hardening and Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with TDD checkpoints.

**Goal:** Complete the F00 monorepo foundation, remove high dependency findings, and produce a reviewable PR targeting `develop`.

**Architecture:** Keep Hono as the API monolith, Next.js as the web app, and PostgreSQL private behind a local Caddy reverse proxy. CI runs reproducible workspace checks and security scans with least privilege.

**Tech Stack:** pnpm 11.25.0, TypeScript strict, Hono, Next.js, Drizzle, PostgreSQL, Docker Compose, Caddy, Vitest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-02-monorepo-foundation-design.md`, `docs/superpowers/plans/2026-09-02-monorepo-foundation.md`, `docs/security/security-requirements.md`.

## Global Constraints

- Work only on `fix/f00-hardening`; target PR is `develop`.
- Tests are written and observed failing before production implementation.
- Do not modify protected specifications, validated tests, migrations, branding, or the AI access policy.
- Do not introduce secrets, production data, public PostgreSQL ports, wildcard CORS, or root runtime containers.
- Keep `@jdr-hub/database` server-only and use parameterized Drizzle queries.
